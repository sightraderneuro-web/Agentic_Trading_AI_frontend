How it works

Three steps between an idea for an agent and trusting it with real money.

  1. Build

    Assemble an agent from modules, or connect one you’ve already built. Set its risk limits, its decision logic and the rules it has to follow.

  2. Stress

    Run it through replays of real crises and synthetic shocks: flash crashes, liquidity droughts, fake headlines and broken data feeds.

  3. Review

    Get a report card with every decision and its reasoning, every rule it broke and how it responded when its supervisor stepped in. Fix it, then run it again.

Modules you build an agent from

What we’re building for the beta. Each module can be swapped, tuned and tested on its own.

Risk management
Position sizing, stops, daily loss limits, exposure caps and a kill switch that works when everything else doesn’t.
Decision engine
Signals, LLM reasoning and investment theses, plus the confidence thresholds your agent needs before it acts.
Regulatory controls
Pre-trade checks for short-selling bans, position limits and market-abuse patterns such as spoofing and wash trades, with a full trade log.
Observer
The human or supervisor agent in the loop. Approve, veto or halt trades, and see whether your agent asks permission when it should.
Reporting
Plain-language incident reports, daily summaries and an audit trail that explains why each trade happened.
Bring your own agent
Connect an agent you’ve built elsewhere through an API and put it through exactly the same tests.

Questions

Does Sightrader trade with real money?

No. Sightrader is a simulation and testing environment. It doesn’t connect to your broker, place live orders or hold funds.

Is this investment advice?

No. Sightrader tests how an agent behaves. It doesn’t recommend trades, and results from simulations don’t predict future returns.

Do I need to code?

No. You’ll be able to assemble an agent from modules without writing code. Developers will be able to connect their own agents and write custom modules.

What does the beta cost?

Nothing. Beta testers get full access for free while the beta runs.
